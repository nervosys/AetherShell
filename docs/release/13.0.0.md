# AetherShell 13.0.0 preparation

## Native ownership contract, 2026-10-01

Fs_chown now declares a String path, required Int owner and optional Int group.
Coverage is 550 of 1,171 implementations and 673 of 1,437 callable names,
leaving 621 implementations undeclared. IDs accept 0 through 4294967294;
negative values, the reserved unchanged sentinel, larger values, wrong types,
extra arguments and pipeline input are refused. Omitted group now preserves
the existing group instead of silently assigning the owner's numeric ID.
Malformed group arguments no longer default to the owner.

Unix uses the [standard library's native ownership API](https://doc.rust-lang.org/std/os/unix/fs/fn.chown.html), eliminating the external
chown process and its option parsing. The canonical Unix target must be valid
UTF-8 and passes the WriteLocal guard, including symlink targets and protected
audit paths. Native ownership changes may clear special mode bits or capabilities.
Filesystem failures carry codes instead of false. Non-Unix platforms return
E_UNIMPLEMENTED, and active filesystem transactions are refused before mutation
because their content journal does not reliably restore ownership metadata.

Disposable regressions cover malformed IDs/calls, containment, transaction
refusal and non-Unix support. Unix-only regressions use existing owners/groups
on owned temporary files and cover omitted group, missing files, symlink targets
and protected audit aliases; these native checks remain to be executed on Unix.
Executable examples clean Windows fixtures before the expected unsupported
refusal, and Unix examples only target their temporary files' existing IDs.
No measured latency improvement is claimed for removing the process.

30 declaration examples, 39 migration, 56 text/file, 18 effect ratchet,
14 guard, 14 transaction and eight workspace jail checks. The final 56-test
text/file rerun and workspace Clippy with warnings denied passed, as did
formatting and diff checks. The inventory confirmed 550/1,171 implementations

## Structured file-edit contract, 2026-10-01

File_edit, edit_file and text_edit now declare a String path with direct or piped
operation Records or Arrays. Coverage is 549 of 1,171 implementations and 672 of
1,437 callable names, leaving 622 implementations undeclared. Conflicting input,
extra arguments, unknown operation fields, ambiguous aliases and malformed
operations are refused. Insert and replace require String content; missing or
wrongly typed content no longer silently deletes lines. Line numbers are positive
Ints and descending ranges are refused.

Validated operations retain descending start-line order and stable input order
for ties. Replace and delete clip their end to EOF and refuse out-of-range starts;
insert clips to EOF. A refused batch makes no file changes, including when an
earlier operation has already been applied in memory. Successful results retain
the applied metadata and counts, with success true and an empty failed array.
Lines normalize to LF with a final newline; blank surviving lines are retained.

Regular UTF-8 reads, aggregate edit payload and normalized output are separately
bounded to 64 MiB. Batches are limited to 10,000 edits, one million potential
lines and ten million conservative line-edit work units. Potential lines count
the source plus all inserted/replacement lines before accounting for deletions.
Edits consume owned values and splice replacement lines without repeated inserts;
result arrays are moved rather than cloned. No measured speedup is claimed.

The existing WriteLocal gate covers the resolved path. Transaction snapshots
precede a single atomic publication through an exclusive sibling, replacing the
predictable .aether_tmp filename and coding filesystem failures. Disposable
regressions cover operations, aliases, pipes, tie order, whole-batch refusal,
empty content, read/output/work limits, containment, temporary-name collisions
and rollback.

## Permission-mode contract, 2026-10-01

Fs_chmod and chmod now declare exactly a String path and a mode. Coverage is
548 of 1,171 implementations and 669 of 1,437 callable names, leaving 623
implementations undeclared. Modes accept Int values in 0..=07777 or octal
Strings, optionally prefixed by 0o. Invalid digits, empty or overflowing strings,
negative or out-of-range integers, wrong types, extra arguments and pipeline
input are refused. The octal string "0" now means zero rather than silently
defaulting to 0644; malformed strings no longer use that fallback.

On Unix, the native operation sets mode bits. On Windows, it changes only the
read-only attribute according to the owner-write bit, retaining the existing
platform semantics. Both aliases guard the resolved path before permission
changes, and metadata or permission failures carry codes instead of false.
Active filesystem transactions are refused with E_UNIMPLEMENTED before mutation:
the current content journal cannot reliably restore permission metadata.

Disposable regressions cover aliases, numeric and octal modes, zero mode,
malformed calls, missing paths, containment and active-transaction refusal.
Fixtures restore original permissions before assertions and cleanup, including
Windows read-only attributes. Unix mode-bit assertions remain to be run on Unix.

## Hard-link contract, 2026-10-01

Fs_link now declares exactly two String paths and returns true on successful
hard-link creation. Filesystem failures carry codes instead of returning false;
pipeline input, extra arguments and invalid types are refused. Coverage is 547
of 1,171 implementations and 667 of 1,437 callable names, leaving 624
implementations undeclared.

Both paths resolve against the explicit workspace and pass the WriteLocal gate.
An outside source is refused because a hard link exposes the same underlying
file through a writable destination; file_copy remains available for imports.
Sources must be regular files without symlinks, and destinations must not exist.
The native operation requires the same filesystem. Existing destination files,
directories and symlinks are refused before snapshotting, preserving their state.
Transactions snapshot only the new destination so rollback removes the link
without undoing unrelated later source writes.

Disposable regressions verify binary content, actual shared-file behavior,
rollback, invalid calls, missing paths, directory-source refusal and containment
of both paths. Refused directory destinations are not journalled. Unix-only
symlink regressions remain to be executed on Unix.

positive Int end for numeric ranges. Coverage is 546 of 1,171 implementations

## File copy contracts, 2026-10-01

File_copy, copy_file and cp now declare exactly two String paths and refuse
pipeline input, surplus arguments and invalid types. Coverage is 545 of 1,171
implementations and 663 of 1,437 callable names, leaving 626 implementations
undeclared. Relative paths resolve against the explicit workspace; outside
sources remain valid imports because only destination writes are jailed.

Copies support binary regular files and directory merging. The destination
parent must exist. Source and destination trees must not overlap; source tree
entries and existing destination entries must be regular files or directories,
without symlinks. Tree paths must be valid UTF-8. Preflight validates the entire
plan before writes, bounds it to 10,000 entries including the root and 64 MiB
total, and passes all actual destinations through the write guard.

File copies stream through exclusively created siblings, preserve file
permissions and publish atomically. The remaining byte budget also bounds
source growth during copying. Existing files and new directories are snapshotted
for transaction rollback; existing merge directories are not snapshotted wholesale,
so unrelated later files are retained. A directory copy may be partially applied
on an I/O failure; an active transaction supplies rollback. Filesystem errors are
coded. Disposable regressions cover aliases, binary data, preflight refusals,
limits, imports, containment and rollback. Unix-only symlink and invalid-UTF-8
path tests remain to be executed on Unix.

## Draft release notes

Builtin dispatch and ontology discovery now share more source-reviewed
argument contracts. Aliases of a declared implementation inherit its contract;
explicit declarations retain precedence. Calls with surplus or invalid arguments
can now fail with `E_BAD_ARG` where earlier versions silently discarded them.
This compatibility change warrants the selected major version.

The migration also fixes integer product overflow, swallowed `sort_by` key
errors, corrupted UTF-8 URL decoding, extraction that dropped the final email
or phone token, malformed JSON indexes selecting element zero, and Unicode
field previews that could panic. AgenticBinary refuses out-of-range byte codes
and overflowing payload lengths. UUID and random byte/string generation now run
in process; string generation handles Unicode and large character sets without
short results or an infinite rejection loop. Random sizes are bounded to
1,048,576 bytes or characters per call.

The earlier latency and throughput work is included in this release line.
Its measurements and methodology are recorded in
[`perf-2026-09-29-followup.md`](../../benches/agentic/results/perf-2026-09-29-followup.md).

Release preflight now checks the root package version, existing tags and Git
command failures. The workflow verifies the requested version against Cargo.toml
before creating a public release. Registry publication still depends on each
registry's credential preflight.
