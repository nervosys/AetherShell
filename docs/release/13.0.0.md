# AetherShell 13.0.0 preparation

Status: in development; not ready to tag. The maintainer selected 13.0.0 for
the stricter builtin contracts. Published metadata remains at 12.0.2 until
release finalization.

## Draft release notes

Builtin dispatch and ontology discovery now share more source-reviewed
argument contracts. Aliases of a declared implementation inherit its contract;
explicit declarations retain precedence. Calls with surplus or invalid arguments
can now fail with `E_BAD_ARG` where earlier versions silently discarded them.
This compatibility change warrants the selected major version.

The migration also fixes integer product overflow, swallowed `sort_by` key
errors, corrupted UTF-8 URL decoding, extraction that dropped the final email
or phone token, malformed JSON indexes selecting element zero, and Unicode
field previews that could panic. AgenticBinary refuses out-of-range byte codes
and overflowing payload lengths. UUID and random byte/string generation now run
in process; string generation handles Unicode and large character sets without
short results or an infinite rejection loop. Random sizes are bounded to
1,048,576 bytes or characters per call.

The earlier latency and throughput work is included in this release line.
Its measurements and methodology are recorded in
[`perf-2026-09-29-followup.md`](../../benches/agentic/results/perf-2026-09-29-followup.md).

Release preflight now checks the root package version, existing tags and Git
command failures. The workflow verifies the requested version against Cargo.toml
before creating a public release. Registry publication still depends on each
registry's credential preflight.

## Migration progress, 2026-09-29

`cargo run --example signature_inventory` enumerates dispatch without executing
builtins. It reports 450 declarations, 450 of 1,171 implementations fully covered,
and 535 of 1,437 callable names covered. There are 721 implementations remaining.
Declarations must continue to come from reading bodies, with worked examples;
state-changing examples require isolated fixtures or a disposable environment.

Validation of this tranche on Windows: 2,482 workspace tests passed, including
doc tests, with `LC_ALL` unset for the locale tests. The 30 declaration tests and
10 migration regression tests also passed separately. Workspace Clippy with
warnings denied, formatting, workflow YAML parsing, package file listing,
three Python release-version tests, and seven simulated release preflight checks
passed. The preflight checks passed under PowerShell 5.1 and PowerShell 7.
Cross-platform CI and catalogue probe gates still need to run on the final release tree.

## Migration progress, 2026-09-30

The next 22 source-reviewed declarations cover tool and syntax discovery, AI
registry metadata, environment/configuration reads, telemetry reports, and file
writing, appending, patching, insertion, moves and directory creation. Coverage
is now 472 of 1,171 implementations and 578 of 1,437 callable names, leaving
699 implementations undeclared.

Provider listings and telemetry groups now use stable ordering. Telemetry
reports refuse unsupported options and incorrectly typed category filters.
Malformed patch instructions are refused before reading or changing the file.
File patch failure messages truncate by characters, avoiding Unicode panics.
Atomic writes use an exclusively created, unique temporary file in the target
directory; concurrent writers no longer share a temporary path, and a failed
write cleans up its own temporary file. File I/O failures use coded refusals.

Every new file-editing example creates and removes a disposable directory.
The added regression tests exercise parallel writers, failed-write cleanup,
malformed patches, Unicode searches and telemetry option validation.

Validation of this tranche on Windows: 2,489 workspace tests passed, including
all 16 migration regressions and nine write-evidence checks. Workspace Clippy
with warnings denied, formatting and workflow YAML parsing passed. The release
preflight now verifies the script's repository root and reads that root's
manifest; eight simulated checks passed under both PowerShell 5.1 and 7,
including refusal from the wrong repository. No real tags were created or pushed.

## Release checklist

The release version guard uses Python 3.11 or newer (`tomllib`); local validation
used Python 3.12. PowerShell preflight tests run without real Git operations.

- [x] Select 13.0.0 for the compatibility change.
- [x] Add alias contract inheritance and canonical declaration uniqueness checks.
- [x] Add repeatable signature coverage inventory.
- [x] Verify release preflight with simulated failures, without tagging or pushing.
- [x] Verify root-version matching and malformed version rejection.
- [ ] Finish the builtin signature migration and remove the interim undeclared test.
- [ ] Pass workspace tests, Clippy and the catalogue probe gates on the final tree.
- [ ] Validate state-changing and hardware-specific contracts in suitable environments.
- [ ] Update the root and LSP versions, lockfile, package metadata and OpenAPI together.
- [ ] Finalize release notes and installation instructions.
- [ ] After an authorized tag exists, compute its real source archive SHA-256 and
      update the Homebrew formula; never invent a prepublication checksum.
- [ ] Verify binaries and registry publication outcomes for the tagged version.

The release workflow creates a public release before binary builds finish.
Successful initiation does not establish that every artifact or registry package
has been published. No 13.0.0 tag or publication is part of this preparation.

## HMAC follow-up, 2026-09-30

The source-reviewed HMAC contract raises coverage to 473 of 1,171
implementations and 579 of 1,437 callable names, leaving 698 implementations
undeclared. HMAC now runs in process on every platform. Unix previously failed
to send the message to OpenSSL; Windows silently selected SHA-256 for unknown
algorithms. Unknown algorithms and malformed algorithm arguments now return
`E_BAD_ARG`. Existing MD5 and SHA-1 options retain the FIPS policy gate.

Reference-vector tests cover all five algorithms, empty messages and keys,
and keys longer than the digest block size. The release remains incomplete.

Validation: all 56 targeted migration, contract and write-policy tests passed;
workspace Clippy with warnings denied, formatting, and diff checks passed.
The inventory independently confirmed the counts above.
